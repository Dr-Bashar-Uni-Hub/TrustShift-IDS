# TrustShift-IDS: label-free shift monitoring for selective intrusion detection — an evaluation

Repository: https://github.com/Dr-Bashar-Uni-Hub/TrustShift-IDS

Code, frozen results, and reproduction material for:

> B. ALHAJAHMAD. *Can Label-Free Shift Monitoring Make Selective Intrusion Detection Reliable? An Evaluation under Synthetic, Cross-Dataset, and Unseen-Attack Shift.* Submitted to the *Journal of Cyber Security Technology* (2026).

The study evaluates TrustShift-IDS, a mechanism that maps a window-level, label-free Shift Severity Score (SSS) to source-calibrated acceptance thresholds for frozen XGBoost intrusion detectors trained on CICIDS2017. The mechanism is compared with static thresholds, alternative label-free monitors (single-evidence monitors and ATC), and a label-informed oracle. The evaluation covers cross-dataset transfer to CSE-CIC-IDS2018, leave-one-attack-out evaluation, controlled perturbations, compound shifts, and constructed deployment sequences.

**Post hoc analyses.** All comparative baselines were specified after the frozen results were known. They are marked *POST HOC* in the code, the results, and the manuscript. The frozen mechanism was never modified. See [`docs/DESIGN_HISTORY.md`](docs/DESIGN_HISTORY.md).

## Quick start: reproduce every number in the paper from the exported results

```bash
pip install -r requirements.txt
cd analysis
python run_all.py
```

This regenerates `results/derived/numbers.json` (Tables 6–8), `results/derived/stats.json` (tests and intervals), the CSE-CIC-IDS2018 family table, and `figures/Figure_1.png`–`Figure_5.png`. No GPU or raw data is required.

## Full re-run from raw data

1. Download CICIDS2017 and CSE-CIC-IDS2018 from the Canadian Institute for Cybersecurity (see [`docs/DATA_AND_ARTIFACTS.md`](docs/DATA_AND_ARTIFACTS.md)).
2. Run notebook 01 (V1, Steps 1–12.9), then notebook 02 (V2), in Google Colab (a high-RAM runtime is sufficient).
3. Run notebooks 03 and 04. Each cell first reproduces the frozen results and stops if any difference exceeds 1e-12.
4. Copy the exported CSVs into `results/` and run `analysis/run_all.py`.

The notebooks expect the Google Drive layout `MyDrive/TrustShift_IDS/...`. Change `BASE` in the first cell of each notebook if your layout differs.

## Environment

Python 3.13, NumPy 2.1.3, pandas 2.2.3, scikit-learn 1.6.1, SciPy 1.16.3, XGBoost 3.4.1. XGBoost inference runs on the CPU, so predictions are bit-identical to the frozen results.
